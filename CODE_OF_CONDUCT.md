# Code of Conduct (resumo)

Compromisso com ambiente técnico, objetivo e respeitoso. Comportamento esperado: foco em fatos verificáveis, revisão por evidência, sem assédio ou discriminação. Violações: reportar via issue/PR aos mantenedores. Baseado no Contributor Covenant; versão completa será adotada na F3 sem mudar este compromisso.
